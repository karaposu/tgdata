## Assembly check — final preferred contract

Retain Innovation2 assembly1–12 **with clause5 replaced**:

> Observation retrieval is synchronous and local in idle, active, closing and closed
> states. It returns the safely captured values and loss indication available at
> that instant, then atomically clears the retained values/tally on the owning loop.
> It requires no source/admin admission and no live client or backend. It invokes
> no application code and makes no claim that source work, settlement or progress
> publication has completed. Later captures belong to later retrievals.

Retain finite count/byte limits; drop incoming on overflow/oversize with loss visible;
secondary capture failure never replaces source truth; returned values are independent.
The application owns processing and any tasks it creates. Pool close owns only source/
client work. Providers must not await their pool's lifecycle. Detectable active-scope
reentry refuses before mutation; no universal wait-graph oracle is promised.

Emergent benefit: the pool has no arbitrary observer program to time out, cancel or
join. Exact source-outcome precedence and retained physical retirement remain separate
necessary guarantees, so this is not a magic buffer fix for the two existing bugs.
The user-facing callback change is deliberate and limited to the unmerged pool API.

Axes checked: availability, finality, reporting existence, intervention shape, value
ownership and supported lifecycle states. Each final assembly claim has F/G/C or
I2's tested3F/2F/1F trace; no newly inherited default. No source/result/store redesign.
