## Assembly and grounding

A2 = Q1F + Q2F + Q3F + Q4F. Stable logical entity updates become recoverable across raw deliveries without a second source progress engine. Required runtime order: authoritative open → transaction/current prior → pure combine → durable posts and scoped receipt → original source ack. Lost ack retries from committed receiver data; missing receiver state refuses. A capture that lacks confirmed pending source delivery remains data only; this example must never synthesize ack authority from it.
